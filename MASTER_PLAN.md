# Family Memories Master Plan

## Mission

Family Memories exists to preserve the stories, laughter, traditions, and adventures of our family so they can be shared, rediscovered, and enjoyed for generations.

## Core Idea

Family Memories is a private family memory app.

It is organized around:

- Events
- Adventures
- Photos
- Comments
- People
- Family members

## Main Structure

Family Memories
- Events
  - Adventures
    - Photos
    - Comments
    - People in the memory

## Version 1 Goals

Version 1 should allow family members to:

- Create an event
- Add adventures to an event
- Upload photos to an adventure
- Add captions
- Comment on adventures
- See recent activity on the home page
- Log in securely
- Search memories

## Important Design Decisions

### Events are the main organizer

Events include things like:

- DeeDee and Papa Camp 2025
- Christmas 2025
- Florida Vacation
- Birthdays
- Bus Adventures

### Adventures belong to events

An event can have many adventures.

One day may include several adventures.

Example:

- Dinosaur Valley
- Ice cream stop
- Campfire
- Train ride

### Adventures are grouped by date automatically

The user should not have to create "Day 1" or "Day 2."

Each adventure has a date, and the website groups adventures by date.

### Comments should create activity

When someone comments on an adventure, that comment should appear on the home page to encourage family members to revisit memories.

### Remembering loved ones

People like Papa Rick should not be hidden on one page only.

The app should allow people to be tagged in memories so their photos, stories, and comments naturally live throughout the scrapbook.

There may also be a Family Legacy or Tribute section later.

## Version 2 Ideas

- Memory of the Day
- Family traditions
- Printable keepsake books
- AI captions
- AI yearly summaries
- Notifications
- Maps
- Mobile app / Progressive Web App

## Guiding Rule

Every feature should answer this question:

Will this help the family preserve or enjoy a memory?
